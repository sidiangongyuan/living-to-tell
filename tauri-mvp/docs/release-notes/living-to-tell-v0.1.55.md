# Living to Tell Preview 0.1.55

0.1.55 introduces in-app Google account authorization for Gemini AI models and improvements to AI profile configuration.

## What's New

- **In-App Google OAuth for Gemini**: Authorize your Google account with one click directly inside the application. No terminal commands, Node.js, or CLI installation required.
- **Direct Code Assist Integration**: Gemini requests communicate directly with official Google Code Assist endpoints using securely stored local credentials.
- **Relay Model Discovery**: Automatically preview available models from OpenAI-compatible relay services.
- **Local Scanner Update**: Automatically detects authenticated Google accounts on the system and imports them into AI profiles.
